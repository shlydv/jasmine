💾 Backup & Restore

The app works offline after it has been opened once, but browser storage is device-specific. Use Export regularly until cloud sync is configured.

⬇️ Export — Save a Backup

Downloads all tenant data and billing history as a .json file. Keep this file safe — it's your full backup.

Undo / Revert

The app keeps the last 20 saved changes on this device. This can restore an accidental checkout, tenant edit, bill, import, delete, or new renter.

⬆️ Import — Restore from Backup

Select a previously exported .json backup file. Warning: this will replace all current data.

ℹ️ How to use Backup

  • Tap Download Backup File every month after entering bills — saves to your Downloads folder
  • If you open this file on a new device or browser, tap Choose Backup File to restore
  • The backup file name includes today's date so you can keep multiple versions

📡 Offline access

On Android/Chrome, open the website once while online and choose Install app or Add to Home screen from the browser menu. It will then open from the phone even without internet. Data entered offline stays on that device until you export or connect cloud sync.
